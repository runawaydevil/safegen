# Gerador de Chaves Seguras

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PHP Version](https://img.shields.io/badge/PHP-8.0+-blue.svg)](https://php.net/)
[![GitHub Stars](https://img.shields.io/github/stars/runawaydevil/safegen?style=social)](https://github.com/runawaydevil/safegen/stargazers)

Um gerador de chaves seguras desenvolvido em PHP que permite gerar diferentes tipos de chaves criptográficas.

## Funcionalidades

- Geração de chaves hexadecimais de 64 caracteres
- Geração de chaves em Base64
- Geração de UUID v4
- Geração de chaves com caracteres especiais
- Interface responsiva e moderna
- Copiar chaves com um clique

## Requisitos

- PHP 8.0 ou superior
- Servidor web (Apache, Nginx, etc.)

## Instalação

1. Clone o repositório:
```bash
git clone https://github.com/runawwaydevil/safegen.git
```

2. Coloque os arquivos no diretório do seu servidor web

3. Acesse o arquivo `index.php` através do navegador

## Uso

1. Acesse a página principal
2. As chaves serão geradas automaticamente
3. Clique no botão "Copiar" para copiar a chave desejada
4. Use o botão "Gerar Novas Chaves" para gerar um novo conjunto de chaves
